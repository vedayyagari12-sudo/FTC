01 — About

A student robotics program run like an engineering firm.

Torque Tyrants is a FIRST Tech Challenge team of eight students from Light Ridge High School and Willard Middle School in Aldie, VA.

We started competing in the 2025–26 season and are now in our second year. Along the way we've designed, built, and programmed competition robots, learning CAD, fabrication, Java, and control systems along the way. We run our own subteams, budget, and outreach, the same way a real engineering organization would.

FIRST Tech Challenge is an international competition for students in grades 7–12. Teams build a robot to play a new head-to-head game each season, and are judged just as much on engineering documentation, community outreach, and Gracious Professionalism.

02 — Engineering

Designed in CAD, built in-house, tuned match after match.

Control
REV Control Hub + Expansion Hub

Dead-wheel odometry + IMU fusion
Scoring
Dual-stage linear slide with active intake
Vision
AprilTag detection for autonomous alignment
Weight
Under the 42 lb competition limit
Code
Java, FTC SDK, version-controlled in Git

Design process

  1. 01Define game strategy and scoring priorities.
  2. 02Sketch and prototype multiple mechanism concepts.
  3. 03Test prototypes against measurable cycle-time targets.
  4. 04Model the winner in CAD and fit-check the assembly.
  5. 05Fabricate, assemble, and instrument the subsystem.
  6. 06Test, collect data, and iterate before every event.

Software

  • Java codebase built on the FTC SDK and tracked in Git.
  • Odometry-based autonomous with path following and AprilTag alignment.
  • Field-centric mecanum driving with adjustable speed profiles.
  • PID-controlled slides and arm with preset scoring heights.
  • Live telemetry dashboards for rapid tuning between matches.

Problems we've solved

Inconsistent autonomous scoring
Added dead-wheel odometry and AprilTag alignment, making autonomous far more repeatable.
Slow scoring cycles
Redesigned intake geometry and shortened slide travel to cut seconds off every cycle.
Chassis flex under load
Triangulated the frame and moved to a stiffer extrusion profile without adding weight.
Wiring failures at competition
Standardized connectors, added strain relief, and built a pre-match electrical checklist.
